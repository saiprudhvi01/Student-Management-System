# Student Management System

A Flask-based student academic management system for managing students, subjects, attendance, and marks.

## Features

- Student management
- Subject management
- Attendance tracking
- Marks management
- Admin and teacher login
- Responsive pastel UI

## Tech Stack

- Python
- Flask
- Flask-SQLAlchemy
- Flask-Login

## Run locally

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Start the app:
   ```bash
   python app.py
   ```
3. Open:
   ```text
   http://127.0.0.1:5000/login
   ```

## Default login

- Admin: `admin` / `admin123`
- Teacher: `teacher` / `teacher123`
